# Portal Web Corporativo B2B - Taller Industrial Alkan S.A.S.

Repositorio oficial del proyecto de desarrollo del portal web institucional y plataforma de cotización técnica B2B para la empresa **Taller Industrial Alkan S.A.S.** (Guadalajara de Buga, Valle del Cauca, Colombia).

Proyecto desarrollado en el marco de la **Etapa Productiva del SENA**.

---

## 📌 Información del Proyecto

- **Empresa:** Taller Industrial Alkan S.A.S.
- **Sector:** Metalmecánica, Mecanizado de Precisión, Corte Plasma CNC y Mantenimiento Industrial.
- **Desarrollador / Aprendiz SENA:** Dilan Hernández
- **Supervisión Empresarial:** Paola Villada (Jefe de Etapa Productiva) / Gerardo García (Representante Legal)
- **Fecha de Inicio:** 19 de noviembre de 2026
- **Estado Actual:** Fase 1 - Análisis, Requisitos de Software y Diseño UI/UX.

---

## 📂 Estructura del Repositorio

```text
AlkanWeb/
├── DiagramasUML/        # Modelado de Casos de Uso y Flujo de Datos (Draw.io)
├── DocumentacionERS/    # Especificación de Requisitos de Software formal (IEEE 830)
├── RecursosVisuales/    # Logos corporativos originales, brochure e insumos gráficos

```

---

## 🛠️ Tecnologías y Metodología

- **Análisis y Modelado:** Estándar IEEE 830, UML (Casos de Uso, Actividades).
- **Diseño UI/UX:** Figma (Prototipado Mobile-First y Desktop).
- **Marco Legal:** Ley 1581 de 2012 (Habeas Data) y Ley 527 de 1999 (Comercio Electrónico en Colombia).
